# DiscordSync

DiscordSync is a personal helper operated by helix4u for troubleshooting public
Discord support threads. It synchronizes relevant conversations and attachments
into a local workspace so the operator can investigate issues, follow unresolved
questions, and maintain support reports.

This repository contains its public policy documentation:

- [Privacy policy](PRIVACY.md)
- [Terms of use](TERMS.md)

The helper is currently used by one operator. It is not offered as a public bot
installation service. Support questions and requests about a copied thread can
be raised directly with the operator handling that support conversation.
